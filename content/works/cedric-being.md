## 为什么做这个网站

作品、想法与经验容易散落在不同的平台里。这个网站希望提供一个自己的空间，让它们有清晰的位置，也让访问者能够沿着兴趣继续探索。

首页的「念念不忘，必有回响」，是这个空间的起点。

## 一个关于连接的首屏

两只手从画面两侧慢慢靠近，始终保留一点距离。画面由 Canvas 实时绘制，使用黑白图片的亮度生成大小不同的点，形成横向扫描行。

- 双手缓慢漂移、呼吸与转动。
- 两组姿态按不同的时间切换，以逐点溶解形成过渡。
- 暖白色画面中，按钮下方的彩虹微光是唯一的色彩。
- 可以暂停动画，也会响应系统的减少动态效果设置。

## 让内容有自己的位置

作品与文章分别拥有目录页，使用分类、标签和搜索来组织。首页只保留少量精选，详细过程放进独立页面。

文章的目录、阅读宽度、代码块、表格与引用使用统一排版。作品可以附带体验地址和源码入口，既展示成果，也记录取舍。

## 用文件维护

内容保存在 Markdown 或 HTML 文件中。标题、分类、标签、摘要等信息写在文件头，导入后自动生成目录与详情页，推送到 GitHub 后重新构建网站。

这件作品仍在生长。接下来会随着真实内容的积累，继续调整阅读与浏览体验。
