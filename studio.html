从导入到发布

1. 在本机运行 npm run dev，使用此工作台导入文件。内容会保存到 content/articles/ 或 content/works/，网页立即重新生成。

2. 查看详情页，确认排版。需要调整时编辑原文件，或者勾选「更新已有的同名内容」重新导入。

3. 将内容文件提交并推送到 GitHub，自动部署更新。也可以直接在 GitHub 上传文件：

上传文章 ↗ · 上传作品 ↗ · 查看内容模板 ↗

图片放入 content/assets/，正文使用 ../assets/图片名.png。HTML 支持正文、图片、表格与链接，脚本、内嵌页面和自定义样式会移除，以统一阅读体验。
